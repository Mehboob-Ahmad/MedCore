# Prompt 07 — Appointment Module

> AI prompt for implementing the Appointment booking and management system.

---

## Objective

Build a robust appointment scheduling system supporting booking, rescheduling, cancellation, and status tracking.

## Tasks

1. Search doctors by specialty, location, and availability
2. Book appointment with time slot selection
3. Reschedule and cancel appointments
4. Appointment status workflow (Pending → Confirmed → In Progress → Completed / Cancelled)
5. Automated reminders (email, push notification)
6. Conflict detection and prevention

## Constraints

- Minimum 1-hour advance booking
- Minimum 4-hour advance cancellation
- No overlapping appointments for the same doctor
- Maximum 60-minute appointment duration
- One active appointment per patient per doctor
